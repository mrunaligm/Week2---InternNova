# Week 2: Python for AI & Data Handling

## Contents
- `Week_2_Python_AI_Data_Handling.ipynb`: notebook for all five tasks
- `week2_ai_data_handling.py`: Python script
- `student_performance_raw.csv`: practice dataset with missing values and duplicate row
- `student_performance_cleaned.csv`: cleaned dataset and derived columns
- `Week_2_AI_Data_Handling_Report.pdf`: formatted report
- `visualizations/`: exported graphs

**Dataset:** Synthetic and for educational practice only.

## Install dependencies
```bash
python -m pip install numpy pandas matplotlib jupyter
```
Launch Jupyter in this folder using `jupyter notebook`, open the `.ipynb`, and run cells from top to bottom. Keep both CSV files in the same folder as the notebook.

**Pass rule used:** all three subject scores must be at least 35. Adjust if your institution has a different policy.
